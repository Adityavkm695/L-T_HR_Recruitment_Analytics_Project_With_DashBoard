from pathlib import Path


## 🏢 Project Overview

This project is a **practice-based Recruitment Analytics Dashboard** created using a simulated dataset to demonstrate Business Analysis, Data Analysis, and Dashboarding skills.

The dashboard transforms recruitment data into clear, business-focused insights across the hiring funnel.

## 🎯 Objective

- Track overall recruitment performance
- Analyze the hiring funnel from applications to joining
- Compare recruitment sources and job functions
- Analyze recruiter and location-wise performance
- Monitor monthly recruitment trends
- Measure hiring rate and average time-to-hire

## 🛠️ Tools & Technologies

- 📗 **Microsoft Excel**
- 📌 PivotTables & PivotCharts
- 🧮 Excel Formulas & Calculations
- 📊 Data Analysis & Visualization
- 🎛️ Filters & Interactive Dashboard Elements

## 🔄 Project Workflow

**Data → Cleaning → Analysis → KPI Calculation → Visualization → Dashboard → Insights**
